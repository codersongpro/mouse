ClassZoom
화면 캡처 · 라이브 줌 · 마우스 하이라이트 · 드로잉 · 화면 녹화 (Windows 10 / 11)

홈페이지: https://songpro.app


[ 시작하기 ]

1. 압축을 바탕화면이나 문서 폴더에 풉니다.
   (압축 안에서 바로 실행하면 설정이 저장되지 않습니다)
2. classzoom.exe 를 실행합니다. 화면 오른쪽 아래에 위젯이 나타납니다.
   설치할 것은 없습니다. classzoom.exe 하나로 모든 기능이 동작합니다.
   (처음 녹화할 때 녹화 엔진을 한 번 준비하느라 몇 초 걸립니다)
3. "Windows의 PC 보호" 파란 창이 뜨면  추가 정보 -> 실행  을 누릅니다.
   (전자서명이 없는 개인 제작 프로그램에 늘 뜨는 안내입니다)


[ 위젯 버튼 ]

  카메라           화면 캡처 (클릭하면 창, 끌면 구역. 오른쪽 클릭: 전체 화면·스크롤)
  돋보기           라이브 줌 (누를 때마다 1단계 -> 2단계 -> 3단계 -> 끄기)
  노란 원 + 커서   마우스 하이라이트 켜기/끄기
  연필             드로잉 켜기/끄기
  빨간 점          화면 녹화 시작/정지 (오른쪽 클릭: 모니터 전체 / 영역 지정)
  톱니바퀴         설정
  켜진 기능은 버튼 바탕이 하늘색, 녹화 중에는 연한 빨강으로 바뀝니다.
  버튼에 마우스를 올리면 이름과 단축키가 뜹니다.
  위젯은 늘 다른 창 위에 보입니다. 설정 -> 위젯 탭의 "항상 다른 창 위에 표시"로 끌 수 있고
  위젯 배경색·크기·투명도도 그 탭에서 바꿉니다.


[ 전자칠판 모드 ]

  칠판 앞에서 키보드 없이 손가락으로 쓰는 모드입니다.
  설정 -> 위젯 탭의 "전자칠판 모드"를 켜거나, 위젯을 길게 눌러(오른쪽 클릭) 메뉴에서 켭니다.
  터치 화면이 있는 PC에서는 처음 한 번 켤지 묻습니다.
  - 위젯이 크게 세로로 바뀌고 돋보기 아래 + / - 버튼으로 확대 단계를 바꿉니다.
  - 드로잉을 켜면 위젯 옆에 팔레트가 열립니다.
    색 6가지, 굵게 / 가늘게, 지우개(켜면 손가락으로 지움), 전부 지우기.


[ 단축키 ]

  F6   화면 캡처: 클릭하면 빨간 테두리가 뜬 창, 누른 채 끌면 그 구역
  F7   라이브 줌: 누를 때마다 1단계(150%) -> 2단계(200%) -> 3단계(300%) -> 끄기
  F8   마우스 하이라이트 켜기/끄기
  F9   드로잉 켜기/끄기
  F10  화면 녹화 시작/정지

  Shift + F6                  커서가 있는 모니터 전체 캡처
  Ctrl + Shift + F6           마우스로 끌어 고른 구역만 캡처
  Ctrl + F6                   스크롤 캡처 (화면을 내려가며 긴 그림 한 장으로)

  녹화 중  Ctrl + F10          일시정지 / 계속
  Ctrl + Shift + F10          영역을 골라 그 부분만 녹화

  Caps Lock (누르고 있는 동안)   드로잉. 떼면 꺼지고 그린 것은 화면에 남습니다.
       지우기: Caps Lock + Delete. 대문자 전환은 Shift + Caps Lock.

  확대 중  Ctrl + 마우스 휠   단계 올리기 / 내리기
  확대 중  Esc               확대 끄기

단계별 배율과 마우스 하이라이트 색은 설정(톱니바퀴)에서 바꿉니다.
드로잉 중 쓰는 키는 설정 -> 단축키 탭의 "드로잉 모드 단축키 보기"를 누르세요.


[ 단축키 바꾸기 ]

- 설정(톱니바퀴) -> 단축키 탭에서 칸을 누르고 원하는 키를 누르면 바로 바뀝니다.
  캡처·라이브 줌·하이라이트·드로잉·녹화 단축키를 모두 바꿀 수 있습니다.
  "기본값"을 누르면 F6 · F7 · F8 · F9 · F10으로 돌아갑니다.
- 글자 키는 Ctrl이나 Alt와 함께 눌러야 합니다. F1~F12 같은 기능키는 하나만 눌러도 됩니다.
- 다른 기능이 이미 쓰는 키, Windows가 쓰는 키(Alt + Tab, Alt + F4, Ctrl + Esc 등),
  드로잉 중 되돌리기 키(Ctrl + Z)는 쓸 수 없습니다.
- 다른 프로그램에서도 흔히 쓰는 키(F5 슬라이드 쇼, Ctrl + C 복사 등)를 고르면
  겹친다고 알려 드립니다. 그래도 정하면 앞에 띄운 프로그램의 기능도 함께 실행됩니다.
  (녹화·캡처 키는 앞 프로그램에 넘기지 않으므로 그 프로그램에서는 동작하지 않습니다.
   한글의 F6(스타일)도 ClassZoom이 켜져 있는 동안은 캡처로 동작합니다)
- 예전에 다른 기능을 F6으로 바꿔 두었다면 그 키는 그대로 두고 캡처 단축키를 비워 둡니다.
  설정 -> 단축키 탭에서 캡처 키를 정해 주세요.


[ 확대 기능 ]

- 캡처한 그림이 아니라 실시간 화면입니다. 영상도 그대로 움직입니다.
- 확대 화면은 고정되고 커서만 움직입니다.
  커서를 가장자리 쪽으로 가져가면 그쪽으로 화면이 이동합니다.
- 커서가 가리키는 곳이 그대로 클릭되고 드로잉(F9)으로 확대 화면 위에 그릴 수 있습니다.
- Zoom · Google Meet 화면 공유와 녹화에 확대 화면이 그대로 보이고
  마우스 커서는 하나만 보입니다.
  공유할 때는 "창"이 아니라 "화면 전체"를 고르세요.


[ 화면 캡처 ]

- F6을 누르면 마우스를 올린 창에 빨간 테두리가 뜹니다. 클릭하면 그 창을, 누른 채 끌면 그 구역을 찍습니다.
  Esc나 오른쪽 클릭은 취소입니다.
- 찍은 그림은 바로 클립보드에 복사되어 한글·파워포인트·카카오톡에 붙여넣을 수 있습니다.
- 찍으면 편집 창이 뜹니다. 펜 · 형광펜 · 네모 · 화살표 · 글자 · 모자이크(가리기) · 자르기를 쓰고
  색과 굵기를 고릅니다. Ctrl + Z 되돌리기, Ctrl + C 복사, Ctrl + S 저장.
- 저장하면 사진\ClassZoom 폴더에 PNG 파일로 남습니다. [다른 이름으로…]는 위치와 형식(PNG/JPG)을 고릅니다.
- 확대 중에 찍으면 확대 화면 그대로 찍힙니다. 편집 창을 쓰는 동안은 확대가 잠시 꺼지고
  편집 창을 닫으면 같은 단계로 다시 켜집니다.
- 드로잉으로 그린 것도 함께 찍힙니다. 위젯·하이라이트 원은 찍히지 않습니다.
- 스크롤 캡처(Ctrl + F6): 창을 클릭하거나 구역을 끌면 ClassZoom이 휠을 굴려 내리며 찍고
  한 장으로 이어 붙입니다. 지금 보이는 자리부터 아래로 내려갑니다.
  끝에 닿으면 저절로 멈추고 중간에 Esc나 [멈춤] 버튼을 누르면 거기까지 이은 그림이 편집 창에 뜹니다.
  확대와 드로잉은 찍는 동안 꺼집니다. 동영상처럼 계속 움직이는 화면은 이어 붙이지 못할 수 있습니다.


[ 화면 녹화 ]

- F10을 누르면 3, 2, 1 뒤에 커서가 있는 모니터 전체를 녹화합니다.
  Ctrl + Shift + F10은 마우스로 끌어서 고른 영역만 녹화합니다.
- 녹화 중에는 화면 위쪽 표시창에서 일시정지·정지를 누를 수 있습니다.
  카운트다운과 표시창, 영역 테두리는 영상에 찍히지 않습니다.
- 마이크 소리(목소리)와 컴퓨터 소리가 함께 녹음됩니다.
  마이크는 Windows 기본 녹음 장치를 씁니다. 설정 -> 녹화 탭에서 끌 수 있습니다.
  녹화를 시작할 때 화질(1080p 기본 / 720p / 원본 해상도)을 고릅니다. Enter를 누르면 1080p입니다.
  "다음부터 묻지 않기"를 켜면 설정 -> 녹화 탭의 화질로 바로 녹화합니다.
- 다시 F10을 누르면 동영상\ClassZoom 폴더에 MP4 파일로 저장하고 폴더를 엽니다.
- 라이브 줌 · 하이라이트 · 드로잉 장면도 그대로 녹화됩니다.
