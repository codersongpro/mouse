ClassZoom
수업용 실시간 화면 확대 · 마우스 강조 · 화면 드로잉 (Windows 10 / 11)

내려받기: https://github.com/codersongpro/mouse/releases/latest


[ 시작하기 ]

1. 압축을 바탕화면이나 문서 폴더에 풉니다.
   (압축 안에서 바로 실행하면 설정이 저장되지 않습니다)
2. classzoom.exe 를 실행합니다. 화면 오른쪽 아래에 위젯이 나타납니다.
3. "Windows의 PC 보호" 파란 창이 뜨면  추가 정보 -> 실행  을 누릅니다.
   (전자서명이 없는 개인 제작 프로그램에 늘 뜨는 안내입니다)


[ 위젯 버튼 ]

  노란 원 + 커서   마우스 강조 켜기/끄기
  연필             드로잉 켜기/끄기
  돋보기           화면 확대 (누를 때마다 1단계 -> 2단계 -> 3단계 -> 끄기)
  톱니바퀴         설정
  켜진 기능은 버튼 바탕이 하늘색으로 바뀝니다.


[ 단축키 ]

  F8   마우스 강조 켜기/끄기
  F9   드로잉 켜기/끄기
  F7   화면 확대: 누를 때마다 1단계(150%) -> 2단계(200%) -> 3단계(300%) -> 끄기

  확대 중  Ctrl + 마우스 휠   단계 올리기 / 내리기
  확대 중  Esc               확대 끄기

단축키와 단계별 배율은 설정(톱니바퀴)에서 바꿀 수 있습니다.
드로잉 중 쓰는 키는 설정 -> 단축키 탭의 "드로잉 모드 단축키 보기"를 누르세요.


[ 확대 기능 ]

- 캡처한 그림이 아니라 실시간 화면입니다. 영상도 그대로 움직입니다.
- 마우스를 움직이면 화면이 따라가고, 커서가 가리키는 곳이 그대로 클릭됩니다.
- 확대 중 F9로 드로잉을 켜면 화면이 고정되고, 확대된 화면 위에 그려집니다.
  커서를 화면 가장자리로 밀면 그쪽으로 화면이 이동합니다.
- Zoom · Google Meet 화면 공유와 녹화에 확대 화면이 그대로 보이고,
  마우스 커서는 하나만 보입니다.
  공유할 때는 "창"이 아니라 "화면 전체"를 고르세요.


[ 끄기 ]

작업표시줄 오른쪽 아래 트레이 아이콘을 오른쪽 클릭 -> 종료
