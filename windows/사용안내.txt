ClassZoom
라이브 줌 · 마우스 하이라이트 · 드로잉 · 화면 녹화 (Windows 10 / 11)

홈페이지: https://songpro.app


[ 시작하기 ]

1. 압축을 바탕화면이나 문서 폴더에 풉니다.
   (압축 안에서 바로 실행하면 설정이 저장되지 않습니다)
2. classzoom.exe 를 실행합니다. 화면 오른쪽 아래에 위젯이 나타납니다.
   설치할 것은 없습니다. classzoom.exe 하나로 모든 기능이 동작합니다.
   (처음 녹화할 때 녹화 엔진을 한 번 준비하느라 몇 초 걸립니다)
3. "Windows의 PC 보호" 파란 창이 뜨면  추가 정보 -> 실행  을 누릅니다.
   (전자서명이 없는 개인 제작 프로그램에 늘 뜨는 안내입니다)


[ 위젯 버튼 ]

  노란 원 + 커서   마우스 하이라이트 켜기/끄기
  연필             드로잉 켜기/끄기
  돋보기           라이브 줌 (누를 때마다 1단계 -> 2단계 -> 3단계 -> 끄기)
  빨간 점          화면 녹화 시작/정지 (오른쪽 클릭: 모니터 전체 / 영역 지정)
  톱니바퀴         설정
  켜진 기능은 버튼 바탕이 하늘색, 녹화 중에는 연한 빨강으로 바뀝니다.


[ 단축키 ]

  F7   라이브 줌: 누를 때마다 1단계(150%) -> 2단계(200%) -> 3단계(300%) -> 끄기
  F8   마우스 하이라이트 켜기/끄기
  F9   드로잉 켜기/끄기
  Caps Lock (누르고 있는 동안)   드로잉. 떼면 꺼지고 그린 것은 화면에 남습니다.
       지우기: Caps Lock + Delete. 대문자 전환은 Shift + Caps Lock.
  F10  화면 녹화 시작/정지

  녹화 중  Ctrl + F10          일시정지 / 계속
  Ctrl + Shift + F10          영역을 골라 그 부분만 녹화

  확대 중  Ctrl + 마우스 휠   단계 올리기 / 내리기
  확대 중  Esc               확대 끄기

단축키와 단계별 배율은 설정(톱니바퀴)에서 바꿀 수 있습니다.
드로잉 중 쓰는 키는 설정 -> 단축키 탭의 "드로잉 모드 단축키 보기"를 누르세요.


[ 확대 기능 ]

- 캡처한 그림이 아니라 실시간 화면입니다. 영상도 그대로 움직입니다.
- 확대 화면은 고정되고 커서만 움직입니다.
  커서를 가장자리 쪽으로 가져가면 그쪽으로 화면이 이동합니다.
- 커서가 가리키는 곳이 그대로 클릭되고, F9로 확대 화면 위에 그릴 수 있습니다.
- Zoom · Google Meet 화면 공유와 녹화에 확대 화면이 그대로 보이고,
  마우스 커서는 하나만 보입니다.
  공유할 때는 "창"이 아니라 "화면 전체"를 고르세요.


[ 화면 녹화 ]

- F10을 누르면 3, 2, 1 뒤에 커서가 있는 모니터 전체를 녹화합니다.
  Ctrl + Shift + F10은 마우스로 끌어서 고른 영역만 녹화합니다.
- 녹화 중에는 화면 위쪽 표시창에서 일시정지·정지를 누를 수 있습니다.
  카운트다운과 표시창, 영역 테두리는 영상에 찍히지 않습니다.
- 마이크 소리(목소리)와 컴퓨터 소리가 함께 녹음됩니다.
  마이크는 Windows 기본 녹음 장치를 씁니다. 설정 -> 녹화 탭에서 끌 수 있습니다.
  녹화를 시작할 때 화질(1080p 기본 / 720p / 원본 해상도)을 고릅니다. Enter를 누르면 1080p입니다.
  "다음부터 묻지 않기"를 켜면 설정 -> 녹화 탭의 화질로 바로 녹화합니다.
- 다시 F10을 누르면 동영상\ClassZoom 폴더에 MP4 파일로 저장하고 폴더를 엽니다.
- 라이브 줌 · 하이라이트 · 드로잉 장면도 그대로 녹화됩니다.
