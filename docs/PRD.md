# ClassZoom PRD (제품 요구사항 문서)

| 항목 | 내용 |
|---|---|
| 제품 | ClassZoom: 라이브 줌 · 마우스 하이라이트 · 드로잉 · 화면 녹화 |
| 버전 | 1.2.6 기준 |
| 플랫폼 | Windows 10/11 (exe 하나), macOS 14 이상 (앱) |
| 배포 | GitHub 릴리스, 랜딩페이지 classzoom.songpro.app |
| 가격 | 무료 (MIT 라이선스) |
| 작성일 | 2026-11-17 |

---

## 1. 한 줄 요약

**전자칠판 앞에서 수업 흐름을 끊지 않고 화면을 키우고, 짚고, 쓰고, 녹화까지 하는 도구.** 키 네 개(F7·F8·F9·F10)와 화면 구석 위젯 하나로 모두 한다.

---

## 2. 문제 정의

### 2.1 배경
- 교실에 전자칠판이 들어왔지만 판서·강조·확대·녹화 도구가 제각각이다. 수업 중에 프로그램을 바꾸면 흐름이 끊긴다.
- 교실 뒤쪽 학생과 **저시력 학생**은 화면 글씨를 잘 못 본다. 기본 돋보기는 배율 조절이 번거롭고, 확대 화면이 화면 공유·녹화에 제대로 나오지 않는다.
- 결석생·복습용 **강의 영상**을 만들려면 녹화 프로그램을 따로 배워야 한다.
- 학교 PC는 **설치 권한이 막혀** 있는 경우가 많다.

### 2.2 해결할 문제
| # | 문제 | 지금의 우회 방법 | 불편 |
|---|---|---|---|
| P1 | 판서·강조가 단순하지 않다 | 전자칠판 기본 판서, PPT 펜 | 메뉴가 깊고 프로그램마다 다르다 |
| P2 | 학생마다 보이는 정도가 다르다 | Windows 돋보기 | 배율 조절이 번거롭고 공유·녹화에 커서가 두 개로 찍힌다 |
| P3 | 강의 녹화가 어렵다 | 별도 녹화 프로그램 | 설치·설정이 어렵고 판서·확대와 따로 논다 |
| P4 | 설치가 막힌 PC | 포기 | 쓸 수 있는 도구가 없다 |
| P5 | 학교(Windows)와 집(맥)의 도구가 다르다 | 각각 다른 프로그램 | 손에 익지 않는다 |

---

## 3. 목표와 비목표

### 3.1 목표
1. **단순화:** 네 기능을 키 하나씩으로 켜고 끈다. 처음 쓰는 교사도 1분 안에 쓴다.
2. **맞춤 확대:** 확대 단계별 배율을 학생에 맞춰 정한다 (125~800%).
3. **공유·녹화 친화:** 확대·판서·강조가 화면 공유와 녹화에 보이는 그대로 담기고, 커서는 하나만 보인다.
4. **녹화 한 번에:** F10 한 번으로 목소리·컴퓨터 소리까지 MP4로 저장한다.
5. **설치 없이:** exe 하나(약 55MB)로 바로 실행한다.
6. **가벼움:** 기능을 끄면 CPU를 거의 쓰지 않고, 쓰지 않는 메모리는 돌려준다.

### 3.2 비목표 (이번 범위 밖)
- 동영상 편집 (자르기·자막)
- 클라우드 업로드·공유 링크 만들기
- 학생 기기와의 실시간 화면 공유
- 판서 내용을 파일로 저장·불러오기

## 4. 사용자

| 페르소나 | 상황 | 바라는 것 |
|---|---|---|
| **전자칠판으로 수업하는 초등 교사** | 수업 중 교과서 PDF·PPT를 띄워 설명한다 | 손가락으로 바로 쓰고 지우고, 중요한 곳을 짚고 키운다 |
| **저시력 학생이 있는 학급의 교사** | 특정 학생이 화면을 잘 못 본다 | 학생 시력에 맞는 배율을 정해 두고 한 키로 켠다 |
| **연수 강사·원격 수업 교사** | Zoom·Meet으로 화면을 공유한다 | 확대·판서가 상대 화면에도 그대로 보인다 |
| **강의 영상을 만드는 교사** | 결석생·복습용 영상을 만든다 | 별도 프로그램 없이 수업 화면을 그대로 녹화한다 |
| **집은 맥, 학교는 Windows인 교사** | 두 컴퓨터를 오간다 | 같은 키, 같은 사용법 |

## 5. 핵심 기능 요구사항

### 5.1 라이브 줌 (F7)
| ID | 요구사항 | 우선순위 |
|---|---|---|
| Z-1 | 누를 때마다 1단계 → 2단계 → 3단계 → 끄기 | 필수 |
| Z-2 | 단계별 배율을 설정에서 125~800%로 정한다 (기본 150/200/300%) | 필수 |
| Z-3 | 영상이 움직이는 그대로 실시간 확대 | 필수 |
| Z-4 | 화면은 고정, 커서만 움직임. 가장자리에 닿을 때만 화면 이동 (흔들림 없음) | 필수 |
| Z-5 | 화면 공유·녹화에 확대 화면이 그대로, 커서는 하나 | 필수 |
| Z-6 | Ctrl+휠 단계 조절, Esc 끄기, 단계 표시("2단계 · 200%") | 필수 |
| Z-7 | 확대한 화면 위에 그대로 드로잉 | 필수 |
| Z-8 | 부드럽게 확대·축소 (끌 수 있음) | 권장 |

| ID | 요구사항 | 우선순위 |
|---|---|---|
| R-1 | F10 시작·정지, Ctrl+F10 일시정지, Ctrl+Shift+F10 영역 녹화 | 필수 |
| R-2 | 시작할 때 화질 선택 창: **1080p(기본)** · 720p · 원본, "다음부터 묻지 않기" | 필수 |

## 6. 사용 흐름

### 6.1 전자칠판 수업
1. 수업 전 ClassZoom 실행 → 위젯이 화면 구석에 뜬다.
2. 교과서 PDF를 띄우고 **F8**로 설명할 곳을 짚는다.
3. **F9**로 드로잉을 켜고 손가락으로 밑줄을 긋는다. 중요한 곳은 **V+드래그** 강조 화살표.
4. 뒷자리 학생이 안 보인다고 하면 **F7**로 키운다. 확대한 채로 계속 쓴다.
5. **Esc**로 지우고 다음 장으로 넘어간다.

### 6.2 저시력 학생 맞춤
1. 설정 → 확대 탭에서 1·2·3단계 배율을 학생에 맞춘다 (예: 200/300/400%).
2. 수업 중 그 학생에게 보여 줄 때 **F7** 한두 번.
3. Ctrl+휠로 바로 단계를 오르내린다.

### 6.3 강의 영상 만들기
1. **F10** → 화질 선택 창에서 Enter(1080p).
2. 3·2·1 뒤 녹화가 시작된다. 확대·판서·강조가 모두 담긴다.
3. 쉬는 동안 **Ctrl+F10** 일시정지.
4. 다시 **F10** → MP4 저장 후 폴더가 열린다.

## 7. 비기능 요구사항

| 영역 | 요구사항 |
|---|---|
| 성능 | 기능을 모두 끄면 CPU 0%에 가깝게. 라이브 줌은 화면이 그대로일 때 초당 30번만 다시 그림 |
| 메모리 | 확대를 끄고 20초 뒤 확대 자원 반환, 기능을 끈 뒤 작업 메모리 정리 |
| 용량 | Windows exe 약 55MB (녹화 엔진 포함), 맥 앱 약 2.7MB |
| 호환 | Windows 10(1803 이후)·11, macOS 14 이상, 다중 모니터 |
| 접근성 | 키보드만으로 모든 기능, 터치·펜 입력, 확대 배율 사용자 지정 |
| 개인정보 | 개인정보를 모으거나 보내지 않음. 인터넷은 새 버전 확인(파일 1개 읽기)에만 씀 |
| 보안 | 녹화 파일은 사용자 PC에만 저장. 외부 업로드 없음 |
| 라이선스 | 앱은 MIT, 녹화 엔진 FFmpeg은 LGPL 2.1 고지 포함 |

## 9. 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 서명하지 않은 exe라 "Windows의 PC 보호" 경고 | 처음 실행을 망설인다 | 안내문·랜딩페이지에 "추가 정보 → 실행" 안내, 코드 서명 검토 |
| 학교 PC 보안 프로그램이 녹화 엔진을 막음 | 녹화 실패 | 엔진을 사용자 폴더에 풀어 실행, 실패 시 오류 안내 |
| GPU 녹화를 못 쓰는 PC (원격 데스크톱 등) | 녹화 품질 저하 | GDI 방식으로 자동 전환 |
| 다른 판서·확대 프로그램과 함께 실행 | 화면 겹침 | 사용 방법 창에 안내, ClassZoom끼리는 자동으로 하나만 실행 |
