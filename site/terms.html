3. 이용 조건

  • 수업·강의·업무 등 쓰는 목적에 제한이 없습니다.
  • 화면 캡처와 화면 녹화로 만든 그림·영상의 권리와 책임은 그것을 만든 사용자에게 있습니다.
  • 다른 사람의 저작물이나 학생 이름·얼굴 같은 개인정보가 담긴 화면을 캡처·녹화해 공유할 때는 저작권법·개인정보 보호법과 학교·기관의 규정을 지켜 주세요. 편집 창의 모자이크로 가린 뒤 공유하기를 권합니다.

4. 보증하지 않음과 책임의 한계

ClassZoom은 있는 그대로 제공되며 어떤 보증도 하지 않습니다. 프로그램을 쓰다 생긴 자료 손실, 장애, 그 밖의 손해에 대해 만든 사람은 책임지지 않습니다.

5. 개인정보

  • 개인정보를 수집하거나 외부로 보내지 않습니다. 회원 가입·로그인도 없습니다.
  • 인터넷은 설정 창을 열 때 새 버전이 있는지 확인하는 데에만 씁니다(GitHub의 버전 파일 1개 읽기).
  • 캡처한 그림과 녹화한 영상, 설정 파일은 사용자의 컴퓨터에만 저장됩니다.
  • 이 홈페이지는 다운로드 버튼에 최신 버전을 연결하려고 GitHub에서 릴리스 정보를 읽습니다. 방문 기록을 모으는 분석 도구는 쓰지 않습니다.

6. 함께 쓰는 공개 소프트웨어

  • FFmpeg (GNU LGPL 2.1): Windows 판의 화면 녹화에 수정하지 않고 그대로 씁니다. 라이선스 전문은 zip 판의 licenses 폴더와, 처음 녹화할 때 꺼내지는 %LOCALAPPDATA%\ClassZoom\engine 폴더에 들어 있습니다. 소스: ffmpeg.org
  • AutoHotkey v2: Windows 판을 만든 도구입니다. autohotkey.com
  • Pretendard (SIL Open Font License 1.1): 이 홈페이지의 글꼴입니다.
