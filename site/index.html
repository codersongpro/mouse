왜 ClassZoom인가요

확대해서 녹화했더니
마우스가 두 개로 보인 적 있나요?

일반 확대 도구는 화면 전체를 시스템에서 키우기 때문에, 녹화·공유 프로그램이 확대된 커서와 실제 커서를 함께 찍습니다. ClassZoom은 확대 화면을 하나의 창으로 그려서 이 문제가 없습니다.

일반 확대 도구 기존

  • 녹화·공유 화면에 커서가 두 개
  • 캡처한 정지 화면이라 영상이 멈춤
  • 확대하면 공유 화면에는 안 보이는 경우
  • 확대·드로잉·강조 도구를 따로 실행

ClassZoom 해결

  • 녹화·공유에도 커서는 하나만
  • 실시간 확대 — 영상·애니메이션도 그대로
  • Zoom·Meet 화면 공유에 확대 화면이 그대로
  • 확대·드로잉·강조를 위젯 하나로

기능

수업에 필요한 네 가지,
화면 구석 위젯 하나로

실시간 3단계 확대

F7

누를 때마다 150% → 200% → 300% → 끄기. 화면은 고정되고 커서만 움직여 흔들림이 없습니다.

마우스 강조

F8

커서 주위를 노란 원으로 강조하고, 클릭하면 원이 오므라들어 학생 눈이 따라옵니다.

화면 드로잉

F9

자유선·사각형·원·화살표·레이저 펜. 확대한 화면 위에도 그대로 그립니다.

자주 묻는 질문

궁금한 점

무료인가요?

네, 무료입니다. MIT 라이선스로 배포하며 학교·개인 누구나 쓸 수 있습니다.

따로 설치해야 하는 프로그램이 있나요?

없습니다. 압축을 풀고 classzoom.exe만 실행하면 됩니다. 관리자 권한도 필요 없습니다.

Zoom이나 Google Meet에서 확대 화면이 안 보여요.

공유할 때 특정 ‘창’이 아니라 ‘화면 전체’(모니터)를 고르세요. 모니터가 두 대라면 공유 중인 모니터에서 확대를 켜면 됩니다.

맥(Mac)에서도 되나요?

지금은 Windows 10 / 11 전용입니다.

개인정보를 수집하나요?

수집하지 않습니다. 인터넷은 설정 창을 열 때 새 버전이 있는지 확인하는 데에만 씁니다(버전 파일 1개 읽기).

넷플릭스 같은 영상이 확대 화면에서 검게 보여요.

복사 방지(DRM)가 걸린 영상은 Windows가 확대를 막아 검게 보일 수 있습니다. 일반 영상·유튜브는 그대로 확대됩니다.
